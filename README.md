# Distill Tube

-- INTRODUCTION --

Welcome to Distill Tube.

YouTube is loud. The algorithm optimizes for addiction, not value. Distill Tube changes that. It gives you back your focus.

This app extracts only what you actually want to see. You define your intentions. You set the tags. The app filters out the noise. No infinite scrolls. No endless shorts. Just the pure essence of the creators you value.

State your purpose. Enter the feed. Watch what matters. Archive the best and dump the rest.

This is your content, refined. Reclaim your time.

-- SETUP --

git clone https://github.com/Psyduck000054/distill_tube.git

cd distill_tube

python -m venv venv

source venv/bin/activate 
or venv\Scripts\activate on Windows

pip install -r requirements.txt

-- RUN --
python app.py [The web will be on local server http://127.0.0.1:5000]
